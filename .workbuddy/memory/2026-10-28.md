## 页面打开自动更新最新开奖数据(双保险机制)
- 需求:每次打开页面都展示最新开奖。数据原为静态内嵌会过期。
- 方案 1(页面端):加载后自动尝试多数据源,成功且更新则重渲染整页。源顺序:福彩官网 API(必被 CORS 拦,保底尝试)→ allorigins 代理 → codetabs 代理 → **jsDelivr CDN**(cdn.jsdelivr.net/gh/GZAlex2020/SSQV2@main/draws.json,国内可达、带CORS、实测2.4s)→ raw.githubusercontent(国内常被墙)。状态条显示 loading/ok/fail,可点击手动刷新;数据校验(期号连续、红蓝球范围)防脏数据;hero 区新增 #syncStatus 胶囊。

- 智能文案:在线源全挂时,若内置数据(由 Actions 保证)≤4天新鲜则显示绿色"已是最新",过期才红色警示。
- 验证:线上 2026123 期(10-27)、sync ok、计算正常;Actions run 40616476136 日志确认数据源切换成功。
- 注意:本地与线上 index.html/双色球分析.html 是两份相同文件,改动须同步;浏览器抓取链路在国内仍主要靠 jsDelivr 兜底,CWL 直连因 CORS 永远失败(属预期)。
