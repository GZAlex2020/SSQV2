## 双色球分析 HTML 工具
- 交付 `双色球分析.html`(单文件,双击即可用):内嵌 100 期真实开奖数据(2026011~2026110,最新 2026-09-22),数据来自福彩官网 API `cwl_admin/front/cwlkj/search/kjxx/findDrawNotice`,用 curl 加 Referer 头抓取成功(HTTP 200)。
- 功能:红球个数 6~12 / 蓝球个数 1~5 可选(超标准即复式)、三种策略(均衡/热号/冷号)、点击「开始计算」才出结果、显示注数+每注¥2+合计、3 组单式参考、红蓝球冷热矩阵(频次+遗漏)、和值走势 canvas 图、100 期原始记录表、近30期回测(平均命中 vs 随机基准 6m/33)。
- 引擎要点:`comb(m,6)*n` 算注数;评分=全期热度/近期热度/遗漏的加权组合;选号后做三区覆盖+奇偶均衡修正;回测为 walk-forward(只用 t 期之前数据)。
- 结论(回测实测):统计策略与随机基准接近,hot 略优、cold 略差——已在页面注明"难以显著超越随机",符合预期。
- 验证方式:提取 HTML 内 ENGINE 块用 node 跑 144 组配置断言(0 错误);再用 playwright-core(装在 `~/.workbuddy/binaries/node/workspace`)+ 缓存的 chromium_headless_shell-1243 截图验证 UI,无 JS 错误。
- 遗留:数据为静态内嵌,更新数据需重跑抓取脚本(`cwl_raw.json`/`draws.json` 留在工作区可复用)。
